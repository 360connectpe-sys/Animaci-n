# Character assets

- `character-sheets/`: original illustrations of the main character (unmodified). Keep outfit and look consistent with these.
  - `character-sheet-01-dark-background.png`: turnaround, expressions, outfit pieces, hands and mouth shapes on a dark background.
  - `character-sheet-02-transparent-background.png`: same character on a transparent background.
- `reference-photos/`: real photos of the author's face, used only as reference for facial features (eyes, nose, lips, jaw, brows, hair). Do not copy clothing or backgrounds. No photos added yet.
- `animation-parts/`: future cut-out parts for animation: `head`, `eyes`, `mouth`, `torso`, `arms`, `legs`.
